# 上游订阅导入

- 在「节点」输入框粘贴一个 HTTP(S) 订阅地址，点击「添加节点 / 订阅」。原有 VLESS 直接添加和批量添加继续可用，也支持 Hysteria2 / hy2 链接。
- 上游响应支持明文或 Base64 编码的 VLESS / Hysteria2 链接列表；暂不支持 Clash YAML、VMess、Shadowsocks 等格式。遇到不支持的节点时整次导入失败，避免静默丢失节点。
- 导入后显示真实节点、上游剩余流量、总流量、到期时间和最近成功更新时间；流量数值以 GiB 显示。
- 「更新订阅」或再次添加相同地址会重新获取节点和套餐信息。未变化节点保留停用状态和排序；手动节点不受影响；上游删除的节点会移除。手动删除的上游节点会在更新时重新导入。
- 更新失败保留上次成功数据。当前采用手动更新；Clash 下载本项目订阅时读取已保存的数据，不会主动请求上游。
- 一份配置只有一个上游时，其 `subscription-userinfo` 会返回给客户端；该额度属于上游套餐，不包含额外手动节点。多个上游分别显示套餐信息，不向客户端输出误导性的合并额度或到期日。
- 上游未返回的信息显示为未知，不使用固定的流量或到期时间。「删除上游订阅」同时删除该来源节点。

# 数据与权限

- 数据库初始化事务新增 `subscription_sources` 和可空的 `nodes.source_id`；旧节点、配置归属和订阅 token 保持兼容。初始化使用立即写事务，串行处理并发启动时的表结构变更。
- 所有管理操作校验登录用户及配置归属，变更操作保留同源检查。删除配置同时清理其来源数据。
- 下载仅允许公网 HTTP(S)，逐跳验证解析地址并固定连接 IP；保留 TLS 证书校验，拒绝 HTTPS 降级跳转，限制 3 次重定向、15 秒和 2 MiB。
- 测试使用临时数据库和虚构节点，不在仓库记录真实订阅地址或凭据。
